# Zendokai Karate Club Jaguar

React + Vite landing page for Zendokai Karate Club Jaguar.

## Stack

- React
- Vite
- Framer Motion
- Lucide React for UI icons
- React Icons for social media brand icons

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

```txt
src/
  App.jsx
  main.jsx
  data/siteData.js
  components/
    Header.jsx
    Hero.jsx
    Stats.jsx
    About.jsx
    Programs.jsx
    Schedule.jsx
    Prices.jsx
    Military.jsx
    Coaches.jsx
    Gallery.jsx
    Contacts.jsx
    Footer.jsx
    SectionTitle.jsx
    motion.js
  styles.css
```

Content, links, prices, schedule, and image paths are stored in `src/data/siteData.js`.
Styles and responsive rules are stored in `src/styles.css`.
